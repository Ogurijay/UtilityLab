# CharacterLab · 角色工坊

**成熟度：experimental（实验中）**

一个纯浏览器端的 3D 人物角色工作台，面向普通用户而非专业动画师：
导入模型 → 绑定动画 → 挂武器 → 调帧 → 导出，全程点按钮完成，
所有数据保存在本地浏览器（IndexedDB），不依赖任何服务器。

## 功能总览

| 模块 | 能力 |
| --- | --- |
| 视口交互 | **点击选中**部件 / 角色 / 挂载物 / 切割平面（选中带**轮廓描边**，蒙皮动画下同样贴合），**移动 / 旋转 / 缩放操纵器**（W / E / R 切换）直接拖拽；**等比缩放锁**默认开启（拖任意轴都整体缩放，防止把脸 / 身体拉变形，可关闭做单轴拉伸）；Delete 删除选中，Esc 取消 |
| 撤销重做 | 全局命令栈（Ctrl+Z / Ctrl+Y）：部件增删改、角色载入 / 合并 / 骨骼覆盖、挂载、动画绑定与裁剪、材质、骨骼映射、资源删除等均可撤销；连续拖拽自动合并为一步 |
| 资源库 | 导入 GLB / GLTF / FBX / OBJ；自动分类为模型 / 动画 / 道具；自定义文件夹归档、搜索、重命名、更改类型、下载源文件、删除（可撤销）；自动生成三维缩略图 |
| 实时预览 | PBR 渲染、环境光照、软阴影、轨道相机、网格与骨骼可视化、一键截图 |
| 模型编辑 | 变换（拖拽数值框或视口操纵器）、一键落地 / 标准身高、部件显隐、材质颜色与金属度 / 粗糙度、线框、形态目标滑杆 |
| 模型切割 | **按身体部位与组合**（头 / 躯干 / 四肢 / 双臂 / 双腿 / 上半身，依据蒙皮权重逐三角形分离）；**按切割平面**（平面可用操纵器任意移动旋转，支持只保留单侧）；**按子网格拆分**。结果自动入库，可勾选直接进拼装台 |
| 模型拼接 | 拼装台：切割部件 / 库内模型自由组合，视口选中 + 操纵器摆放（枢轴在部件中心），支持 X 轴镜像，一键合并为单一新模型（按材质合批） |
| 骨骼覆盖 | 一键**用 Manny / UEFN 标准骨架整套替换**：已蒙皮模型走**骨骼移植**（标准关节按模型比例适配、逐顶点权重重映射）；静态 / 拼装模型走**自动蒙皮**。覆盖后骨架命名与层级与 Manny 完全一致 |
| 骨骼映射 | 自动识别 Mixamo / UE·Manny / VRM / Biped 等命名体系并映射到 23 个标准槽位；可手动修正；另有保守的"仅重命名对齐"模式 |
| 动画重定向 | 世界空间旋转增量重定向器：跨 T/A-pose、跨单位、跨层级；同名骨架直接绑定（保留手指细节，髋部高度按体型自适应） |
| 武器挂载 | 插槽预设 + 任意骨骼；视口选中挂载物后用操纵器微调，或用数值框精调 |
| 时间轴 | 播放 / 变速 / 循环 / 原地播放、逐帧显示、拖手柄裁剪帧区间另存新片段 |
| 内置资产 | 仅 3 段程序化示例动画（待机 / 行走 / 挥手），可绑到任何人形骨架；无预置模型 / 武器 |
| 导出 | 整角色导出标准 GLB（可选挂载物与动画子集）；「存入库」把当前角色连动画存回资源库 |

## 运行方式

```bash
npm install
npm run dev        # 开发服务器，默认 http://localhost:8617
npm run build      # 类型检查 + 生产构建（输出 dist/）
```

> 端口在 `vite.config.ts` 里改；本机 5173 处于 Windows 保留端口段，故默认用 8617。

## 使用流程

1. **选角色**：左侧资源库导入 GLB / FBX 模型（拖文件进窗口也行）→「设为角色」。
2. **切割 / 拼接（可选）**：「部件」页按部位或切割平面切开（结果入库并可直接进拼装台），
   视口里点击部件选中，用操纵器（W 移动 / E 旋转 / R 缩放）自由拼接，合并成新模型。
3. **盖上 Manny 骨骼**：「骨骼」页一键「用 Manny / UEFN 骨骼覆盖」——
   有蒙皮走移植、拼装 / 静态模型走自动蒙皮，之后任何动画都能绑。
4. **绑动画 / 挂武器 / 调帧**：动画点「绑定动画」（跨骨架自动重定向）；
   挂载物在视口选中后可直接拖操纵器微调；时间轴变速、逐帧、裁剪。
5. **导出**：右上角「导出 GLB」或「存入库」。做错了随时 Ctrl+Z。

## 技术要点

- Vite + React 19 + TypeScript + three.js + zustand + idb，无后端。
- 重定向算法：对每对映射骨骼取源骨骼「当前世界旋转 × 绑定世界旋转⁻¹」的增量，
  施加到目标骨骼的绑定世界旋转后换算回本地空间逐帧烘焙（30fps）；
  髋部位移按两副骨架髋高比缩放，天然兼容不同绑定姿势与单位。
- 内置假人、示例动画、训练武器全部程序化生成（遵守仓库
  「不提交数字创意资产」规则，仓库中无任何模型 / 贴图文件）。
- Draco 压缩的 GLB 需联网加载解码器（gstatic CDN）；普通 GLB 离线可用。

## 已知限制

- 单角色工作台：同一时间编辑一个角色（挂载物、拼装台部件不限）。
- 重定向与骨骼覆盖针对 23 个人形标准槽位；手指、面部等额外骨骼在
  **骨骼移植**时权重并入邻近标准骨骼（随父级刚性运动），在
  **同名直接绑定**时不受影响。
- **自动蒙皮**是邻近胶囊段的近似权重，适合人形、姿态接近 T / A-pose 的模型；
  关节过渡不如手工权重平滑，追求精细可在 Blender 等工具里再修。
- **平面切割**的切口是敞开的（不自动补面）；切割 / 拼装会把模型静态化
  （丢弃原蒙皮与形态目标），之后用骨骼覆盖重新绑定。
- 骨骼移植保持模型自身比例（关节位置来自原骨架），骨骼朝向轴为世界对齐
  而非 UE 原生朝向；进 UE / UEFN 后建议用 IK Rig + IK Retargeter 做最终匹配
  （标准命名可被自动识别，基本零配置）。
- `.gltf` 外部引用文件不支持（请用自包含的 `.glb`）；VRM、BVH 暂未支持。
- 未实现撤销 / 重做；材质编辑针对常规 PBR 参数。
- 测试用的模型 / 动画文件请放在本地任意目录，仓库 `.gitignore`
  已全局排除 `*.glb` / `*.fbx` 等资产格式，不会误提交。

## 目录结构

```text
CharacterLab/
├─ index.html / vite.config.ts / tsconfig.json
└─ src/
   ├─ core/            # 三维核心：引擎、加载、角色、骨架快照、缩略图、GLB 导出
   │  ├─ mesh/         # 静态烘焙 / 合批、部位与平面切割
   │  ├─ skeletons/    # 标准骨架定义、自动映射、重定向、骨架适配、移植、自动蒙皮
   │  └─ builtins/     # 程序化假人 / 示例动画 / 训练武器
   ├─ app/controller.ts# 编排层：UI 操作 ⇄ 三维世界 ⇄ 状态镜像
   ├─ store/           # zustand：编辑器状态、资源库
   ├─ db/assetDb.ts    # IndexedDB 持久化（元数据 / 文件内容 / 文件夹）
   └─ components/      # React 界面：资源库、视口、检查器五面板、时间轴等
```
